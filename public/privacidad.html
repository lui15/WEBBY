Política de privacidad de Webby

Última actualización: 16 de noviembre de 2026

Webby es un panel privado que usa únicamente su propietario para seguir el rendimiento de sus propias webs: armamuebles.es, obralocalmadrid.es y mudanzas360.es. No es un servicio abierto al público ni tiene otros usuarios.

Qué datos de Google usa

Con el permiso expreso del propietario, Webby accede solo en modo lectura a:

  • Google Search Console (webmasters.readonly): impresiones, clics, posición media y búsquedas de sus propias webs.
  • Google Analytics (analytics.readonly): visitas, usuarios y eventos clave de esas mismas webs.
  • La dirección de correo de la cuenta de Google, para saber qué cuenta está conectada.

Webby no puede modificar nada en Google, no lee correos, contactos, archivos ni ningún otro dato de la cuenta.

Para qué se usan

Exclusivamente para mostrar al propietario la evolución de sus webs y para que sus asistentes de análisis le den recomendaciones. Los datos no se venden, no se comparten con terceros con fines publicitarios y no se usan para crear perfiles de personas.

Dónde se guardan y cómo se protegen

  • Los datos se guardan en una base de datos privada (Supabase) a la que solo puede acceder la cuenta del propietario.
  • El permiso de Google se guarda cifrado y nunca se muestra en la aplicación.
  • Todas las conexiones van cifradas (HTTPS).

Servicios que intervienen

  • Supabase: base de datos y funciones del servidor.
  • Vercel: alojamiento de la aplicación web.
  • Anthropic (Claude): cuando el propietario pregunta a un asistente, se envía a Claude un resumen de las métricas para generar la respuesta. Anthropic no usa estos datos para entrenar sus modelos.

Cuánto tiempo se conservan y cómo borrarlos

Las métricas se conservan mientras el propietario use Webby. El acceso a Google puede retirarse en cualquier momento desde myaccount.google.com/permissions; al hacerlo, Webby deja de recibir datos y el propietario puede borrar los ya guardados.

Uso de los datos de las API de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.
